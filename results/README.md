# results

All output produced by the analysis pipeline.

```
results/
├── figures/      # PNG figures used in the manuscript and supplement
├── tables/       # RDS tables (Kruskal-Wallis, PERMANOVA, ML metrics, ...)
├── output/       # Larger intermediate objects (igraph network list)
└── large-files/  # gitignored — for >20MB intermediate objects
```

Every file in `figures/` and `tables/` is regenerated by re-running
`code/analysis-code/statistical-analysis.R` (and, for the EDA outputs,
`code/eda-code/eda.qmd`). See the manuscript and supplement for which
figure/table corresponds to which hypothesis.
